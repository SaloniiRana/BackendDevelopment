# Experiment 08: JavaScript Event Handling

## Objective
To implement modern event handling in JavaScript using `addEventListener()`, handle user interactions (mouse, keyboard, and form events), and apply event delegation for dynamically created DOM elements.

## Concepts Implemented
* **Form Handling:** Using `submit` event with `event.preventDefault()` to handle form inputs without reloading the page.
* **Event Delegation:** Attaching a single `click` listener on the parent `<ul>` element to manage clicks on dynamically added task items and delete buttons.
* **Keyboard & Input Events:** Tracking real-time text length with `input` and capturing pressed keys via `keydown` (`event.key`).
* **Mouse Events:** Responding to `mouseenter`, `mouseleave`, and `dblclick` events to dynamically update UI styles and text.

## How to Run
Open `index.html` in any web browser and interact with the checklist form, text input, and mouse event box.
