# Experiment 05: JavaScript Arrays, Objects, and Functions

## Course Details
* **Course Outcome Mapped:** CO2 – Create and build web pages and applications.
* **Unit:** II
* **Bloom's Knowledge Level:** Apply
* **PBL Activity:** Implement a simple data management utility using Arrays and Objects.

## Objective
To write JavaScript programs demonstrating array manipulation, object creation, and different types of function definitions through an interactive Student Record Management Utility.

## Concepts Implemented
* **JavaScript Objects:** Representing each student record with structured properties (`rollNo`, `name`, `course`, `marks`).
* **Array Methods:**
  * `push()` and `splice()` for adding and removing records.
  * `forEach()` for rendering records dynamically into the DOM.
  * `filter()` for extracting top scorers (`marks >= 75`).
  * `map()` for applying grace marks across all student objects.
  * `reduce()` for calculating the class average.
  * `sort()` for ranking students by marks.
* **Function Definitions:** Standard function declarations (`calculateGrade`), arrow functions (`getAverageMarks`), and anonymous callback functions inside event listeners.

## Files Included
* `index.html` — User interface for adding, filtering, sorting, and viewing student records.
* `script.js` — Core JavaScript logic implementing arrays, objects, and utility functions.

## How to Run
1. Open the `Experiment 5` folder.
2. Double-click `index.html` or open it with **Live Server** in VS Code to interact with the data utility in your browser.
