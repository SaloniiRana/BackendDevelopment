# Experiment 07: ES6 Features & DOM Manipulation

## Objective
To understand and apply ES6 (ECMAScript 2015) features in JavaScript and perform dynamic Document Object Model (DOM) selection, content updates, attribute changes, and node creation/removal.

## Concepts Implemented
* **ES6 Features:**
  * Block-scoped variables (`let` and `const`).
  * Arrow functions and template literals (`` ` ``).
  * Object destructuring, default parameters, and spread/rest operators (`...`).
  * ES6 Classes and inheritance (`Course` and `LabCourse`).
  * Asynchronous execution with `Promise` and `async/await`.
* **DOM Manipulation:**
  * Selecting elements via `getElementById()` and `querySelector()`.
  * Updating text safely with `textContent` and modifying attributes with `setAttribute()`.
  * Toggling CSS classes using `classList.toggle()`.
  * Creating and removing DOM nodes dynamically with `createElement()`, `appendChild()`, and `removeChild()`.

## How to Run
Open `index.html` in any web browser (or via VS Code Live Server) and click the buttons to inspect the ES6 output and DOM tree updates.
