# Experiment 12B: State Management Using Sessions & Cookies

## 📝 Theoretical Foundation
* **HTTP is Stateless:** Every request sent between a computer and a server is completely independent. The server has zero natural memory to recognize visitors between page clicks.
* **Cookies:** Key-value pairs stored **directly on the client browser space** to handle light layout options (like theme parameters).
* **Sessions:** Secure tracking records **retained strictly on the server's backend memory allocation map** to safeguard user identity tags.

## 🚀 Step-by-Step Lab Setup
1. Enter the experiment file system container:
   ```bash
   cd Experiment-12B
   ```
2. Build local module library assets:
   ```bash
   npm install
   ```
3. Boot up the real-time node process monitor:
   ```bash
   npm run dev
   ```
4. Access the framework sandbox from your internet dashboard: `http://localhost:4000`
