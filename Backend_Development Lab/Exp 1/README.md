# Experiment 1: HTML5 Elements & Semantic Web Page

## Course Outcome Mapped
* **CO2:** Create and build web pages and applications.

## Objectives
1. Create a well-structured HTML5 web page using appropriate semantic elements.
2. Differentiate between HTML4 and HTML5 structural elements.
3. Apply various HTML5 form input types and attributes.
4. Implement multimedia elements (`<audio>`, `<video>`) in web pages.
5. Understand the Document Object Model (DOM) structure.
6. Create accessible and SEO-friendly web pages using semantic HTML.

## Files Included
* `index.html` — Main HTML5 web page demonstrating semantic layout tags, comparison table, HTML5 form inputs, multimedia players, SVG/Canvas graphics, and interactive tags.

## Key Features Implemented
* **Semantic Layout:** Uses `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>` instead of generic `<div>` tags.
* **HTML5 Form Controls:** Includes `email`, `url`, `tel`, `date`, `number`, `range`, `color`, `search`, and `<datalist>` with built-in validation attributes (`required`, `pattern`, `min`, `max`).
* **Multimedia & Graphics:** Demonstrates native `<audio>` and `<video>` elements with fallback messages, inline `<svg>`, and a `<canvas>` element drawn via JavaScript.
* **Interactive & Accessibility Tags:** Uses `<details>`, `<summary>`, `<progress>`, `<meter>`, `<figure>`, `<figcaption>`, and ARIA/label attributes for screen-reader and SEO compatibility.

## How to Run
1. Open the `Exp 1` folder in VS Code or File Explorer.
2. Double-click `index.html` (or open it with **Live Server** in VS Code) to view the web page in any modern browser.
